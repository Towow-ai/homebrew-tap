# Towow Homebrew Tap

Homebrew casks for Towow products.

```bash
brew install --cask towow-ai/tap/totype
```

| Cask | Product |
|---|---|
| `totype` | [Totype](https://github.com/Towow-ai/totype): voice input method for macOS |

The apps here are signed ad-hoc and not notarized by Apple. After installing, follow the caveats that Homebrew prints to open the app for the first time.
